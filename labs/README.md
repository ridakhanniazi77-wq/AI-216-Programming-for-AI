# Lab 01 – GitHub Setup & First Push

## What this lab does

In this lab, I set up Git and GitHub for the AI-216 Programming for Artificial Intelligence course. I created the required repository structure, added a Python script, created README files, used Git commits, and pushed my work to GitHub.

## Key commands used

- `git init`
- `git add .`
- `git commit -m "message"`
- `git remote add origin`
- `git branch -M main`
- `git push -u origin main`
- `git checkout -b week01-readme-improve`
- `git merge week01-readme-improve`

## What I learned

- I learned how Git tracks changes in a project.
- I learned how to create commits and push files to GitHub.
- I learned how branches can be used to make changes safely before merging them into the main branch.

## AI/ML relevance

Version control is important in AI and machine learning because code, datasets, experiments, and configurations can change frequently. Git helps maintain a history of changes, making work more reproducible and easier to collaborate on with others.
